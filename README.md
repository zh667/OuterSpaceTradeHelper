# 跑商助手 · Outer Space Trade Helper

《Outer Space / 秩序：新曙光》（Steam 3080070）的游戏内跑商助手模组。自用起步，GPL-3.0 开源。游戏内按 **F8** 打开。

## 功能
- **市场**：每个星系有一个“贸易市场”，在该星系有交易功能的空间站点「贸易市场」打开，舰队直接买卖。站名写成“星系·空间站”（例如 寂幕旋区·索拉驿站），各站市场页写明从哪个空间站打开。星球的“地面交易行”是独立的市场，只能在那颗星球上自己基地的贸易站里用，本模组不涉及。
- **跑商计划**：追踪选中的买卖。状态自动改：库存里多出这批货 → ② 已买，待卖；这批货全部从库存里没了 → ③ 已完成，并写明卖在哪个站（普通货看游戏的成交记录，舰载机等特殊货看哪个站的库存多了）。同站同货的多个计划按排队算价格。同一种货的几个计划在库存里不分彼此：卖掉的数量先算给“卖出站正好收到这批货”的那个计划，其次是库存里确实有货的计划，最后按排队顺序。进行中的计划合计算的数量比库存里实际有的多（比如还没买就手动点了「改为已买入」），状态会变成红色的“库存里没有/库存缺 N”，按钮变成「改回待买入」；这些不在库存里的数量不估价，也不占卖出站的排队。“现在最好卖到”列旁的“比计划”是卖到那个站的净赚比计划净赚涨跌多少（点一行看前几个站各自的到手、净赚和涨跌）。计划页顶部和下方汇总已完成的计划：一共赚了多少、按路线排行。计划存在 `plans.json`，重启游戏后还在。
- **跑商建议**：各站之间扣两边税、算上买卖时价格变化后的最佳买卖站和数量；净赚、利润率、航程、每光年净赚，可按任意列排序，可按数据新鲜度、舰队距离、最低净赚、类别、关键字筛选。只用舰队去过（地图上“已探索”）的星系；只在地图上发现、还没去过的星系默认不出现在建议、卖库存和计划的“现在最好卖到”里，勾“含未探索的星系”才算进去。
- **卖库存**：母舰、基地、舰队货仓、DNA 库的东西卖到哪最值钱。
- **各站市场**：每个站的库存、买一个（含税）、卖一个（到手）、税率、能否买、违禁；价格标“实时”或“估”。
- **我的库存**：按位置/类别汇总。
- **后台补算**：选择要补算/初始化的市场（含“一键初始化所有未开过的站”“保持实时”）。每个站交给游戏自己的后台补算 `ensureStoreInitializedAsync`（和打开交易所时一样，在后台线程里算），一次一个站，效果等于你打开了那个站。补算期间偶尔的停顿来自游戏结算产生的垃圾回收（约 10MB/站·天），“保持实时”的站越多越频繁。
- **导出**：`latest.json` 和截图默认在 `%USERPROFILE%/AppData/LocalLow/CatStudio/Outer Space/TradeHelper/`，可在设置页改到游戏目录里本模组的 `data` 文件夹或任意文件夹（`config.json` 固定在默认位置）。

## 准确性
- 税：按游戏结账时用的市场税率（`ApplyTradeTaxRate(getTaxRate())`，整车统一扣），不是每种货自己的税率。
- 特殊货（舰载机、DNA 等）：库存占用按每件的耐久系数累加；卖自己手上的货时，在实时站直接用游戏的出售报价（`getPriceForPlayerSell`，含耐久折价）。
- 站点没有欠结算天数时，价格直接来自游戏自己的计价函数（`GetBasePriceFactor`、`QuoteTrade`、`getPBase`、`getTaxRate`、`getEPool`），与游戏交易所一致。
- 欠天数的站不会被这些函数碰到（它们会触发补算），只读存着的数据估价，并标“估·欠 N 天”。
- 距离与游戏一致：星门航线（`GalaxyDistanceUnit.TryCalculateGalaxyFieldRouteToAu`），显示格式用游戏的 `UIUntils.distanceAu`。

- 每个市场的经济参数（容量、地区偏好）按游戏的经济版本缓存，并存到 `econ-cache.bin`（按存档区分）；每次扫描随机抽查实时值，不一致就整站重读。

## 测试
`python tools/run_isolated.py`（Windows）：把游戏复制到 `local/runtime`，副本的产品名改成 `OS TH Tests`，存档、日志都写到 `LocalLow/CatStudio/OS TH Tests`，原版游戏和玩家存档只读。副本最小化启动，读入玩家最新存档的副本，模组自测：税、普通货、特殊货买入和转卖逐个对比游戏自己的报价函数；在测试存档里真买真卖一批，核对扣款、到账、计划自动状态和卖出站；对比硬盘缓存和实时值；记录扫描耗时和截图；最后写 `selftest-result.json` 并退出。

## 外观
界面用 uGUI + TextMeshPro，字体和贴图在运行时通过游戏自己的 `ResourceLoader` 加载（思源黑体 SDF、交易界面的面板/按钮贴图），取不到时退回同色的纯色图。

## 构建与安装
Windows：`python tools/build.py`（加 `install` 复制到 `<游戏>/mods/TradeHelper`，旧安装先备份到 `dist/replaced-*`）。目标 net472，直接引用游戏 `Outer Space_Data/Managed` 的 DLL。模组布局：`Manifest/manifest.xml` + `v_common/Assemblies/TradeHelper.dll`。启用：游戏模组菜单里启用后重启游戏。

协作规则见 `AGENTS.md`。
